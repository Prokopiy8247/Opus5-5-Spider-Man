# Web Slinger

Игра в открытом мире в стиле Человека-паука: город 3 × 1,5 км, полёты на паутине, бег по стенам, бои с комбо, гаджеты, костюмы, дерево навыков и вражеские базы. Сделана на Godot 4.7, 3D-модели — в Blender.

Игру разработала команда из 4 ИИ-агентов (Тимлид, Фронт, Бэк и QA) на Claude Opus 5.5 в [Sharrowkin IDE](https://www.sharrowkin.dev/).

## Запуск на Windows

1. Скачайте `WebSlinger-Windows.exe`. Если браузер предупредит, что файл скачивают редко, выберите «Сохранить» (в Chrome — «Всё равно скачать»).
2. Запустите файл двойным щелчком.
3. Если появится окно «Система Windows защитила ваш компьютер», нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Предупреждение появляется потому, что у exe нет платной цифровой подписи. Это нужно сделать только один раз.

Требования: Windows 10 или 11 (64 бит), видеокарта с поддержкой DirectX 12 или Vulkan.

## Запуск на macOS

1. Скачайте `WebSlinger-macOS.zip` и откройте его двойным щелчком: рядом появится `Web Slinger.app`. Safari может распаковать архив сам.
2. Перетащите `Web Slinger.app` в папку **«Программы»**.
3. Запустите игру двойным щелчком. При первом запуске macOS покажет, что не может проверить приложение. Нажмите **«Готово»**: игра не нотаризована в Apple, поэтому система блокирует её по умолчанию.
4. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз до сообщения о Web Slinger и нажмите **«Всё равно открыть»**. Подтвердите паролем или Touch ID, затем нажмите **«Открыть»**.

Дальше игра открывается обычным двойным щелчком.

На macOS 14 и старше вместо шагов 3–4 можно нажать на приложение правой кнопкой мыши, выбрать **«Открыть»** и подтвердить.

Если macOS пишет, что приложение «повреждено» и его нужно переместить в корзину, откройте **Терминал** и выполните команду (она снимает с игры пометку «скачано из интернета»):

```sh
xattr -dr com.apple.quarantine "/Applications/Web Slinger.app"
```

Требования: macOS 11 или новее на Apple Silicon (M1 и новее), macOS 10.15 или новее на Intel.

## Управление

| Клавиша | Действие |
|---|---|
| WASD, мышь | Движение и камера |
| Shift | Полёт на паутине (на земле — бег, у стены — бег по стене) |
| Space | Прыжок (в конце рывка — Point Launch) |
| Q | Рывок на паутине (Web Zip) |
| Ctrl | Уворот и отмена атаки (зажать в воздухе — пикирование) |
| ЛКМ | Удар |
| E | Удар паутиной |
| R | Бросок |
| F | Добивание (нужно 3 деления Focus) |
| H | Лечение |
| C | Трюк в воздухе |
| V | Паучье чутьё (сканирование) |
| G или ПКМ | Использовать гаджет |
| Tab, 1–5 | Выбор гаджета |
| K / L / M | Навыки / костюмы / карта |
| Esc | Пауза |
| F1 | Скрыть интерфейс |
| F3 | Меню отладки (время суток, телепорты, бессмертие, опыт, враги) |

## Запуск из исходников

1. Установите [Godot 4.7.2](https://godotengine.org/download/archive/).
2. Скачайте или клонируйте этот репозиторий.
3. Откройте `project.godot` в редакторе Godot и нажмите F5. Или выполните в папке проекта:

   ```sh
   godot --path .
   ```

Первое открытие проекта занимает несколько минут: Godot импортирует текстуры и модели.

## Для разработчиков

Автотесты (QA-сценарии): `godot --path . -- --qa=<smoke|load_all|traversal_bot|combat_bot|city_flythrough|perf_sweep|regression|soak10|animation_gallery>`. Результаты пишутся в `qa/evidence/<scenario>/metrics.json`. Все сценарии подряд — `qa/tools/run_all.ps1`, подробнее в [qa/README.md](qa/README.md).

Исходники 3D-моделей и текстур — скрипты Blender в `assets/blender/`.
